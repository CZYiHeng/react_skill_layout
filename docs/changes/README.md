# 变更设计记录

本目录存放**面向一次具体改造**的设计文档：动机、依据（含代码证据）、取舍、实施顺序与验收标准。
与 [DESIGN.md](../DESIGN.md) 的分工：

| 文档 | 职责 |
|---|---|
| [DESIGN.md](../DESIGN.md) | 系统整体架构的**现状**说明（状态机、协议、安全模型） |
| `docs/changes/*.md` | 某次改造的**设计**与决策记录（为什么改、怎么改、怎么验） |

命名：`YYYY-MM-DD-<主题>.md`。文档一旦实施完成，保留原文（作为决策留痕），实施结果在提交信息与 DESIGN.md 中体现。
